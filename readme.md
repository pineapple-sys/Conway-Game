# Conway's Game Of Life (using Python!)

This is my attempt to reproduce the simple Game of Life.

## Code Architecture

- **`game.py` (game engine/Numpy)**: Logic of the Game
- **`main.py` (display/Pygame)**: Keep the game running and display the result 

## Requirements
- `pygame`
- `numpy`

## Upcoming Features
- `Draw`: Let the player draw on the grid to decide what cells are alive
- `Play/Stop buttons`
- `Infinite Grid` -> **`Movement`**
